# task 10 — api response handler

## описание

анализ ответов api для отслеживания успешных запросов, клиентских и серверных ошибок, а также повторных запросов

## что делает программа

- считает общее количество запросов
- определяет успешные запросы с кодами 200–299
- находит клиентские ошибки 400–499
- находит серверные ошибки 500–599
- выявляет повторные запросы
- определяет эндпоинты с ошибками
- группирует запросы по endpoint
- собирает статистику по каждому эндпоинту
