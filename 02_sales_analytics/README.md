# task 7 — sales analytics

## описание

анализ данных интернет-магазина на основе пользователей и их заказов

## что делает программа

- считает количество пользователей
- считает количество заказов
- вычисляет общую выручку
- рассчитывает выручку каждого пользователя
- рассчитывает выручку по городам
- группирует выручку по категориям товаров
- определяет пользователя с наибольшими расходами

## условия

- данные пользователей представлены в виде списка словарей
- у каждого пользователя есть имя, город и список заказов
- каждый заказ содержит товар, категорию и цену
- выручка рассчитывается на основе стоимости заказов
- покупки группируются по пользователям, городам и категориям
- определяется пользователь, потративший больше всех
