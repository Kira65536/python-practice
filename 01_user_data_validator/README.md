# task 9 — user data validator

## описание

проверка пользовательских данных на корректность и разделение пользователей на валидных и невалидных с сохранением обнаруженных ошибок

## что делает программа

- проверяет наличие username
- проверяет формат email
- проверяет наличие возраста
- проверяет тип возраста
- проверяет возраст на соответствие минимальному значению
- разделяет пользователей на валидных и невалидных
- сохраняет ошибки каждого пользователя

## условия проверки

- username должен быть непустой строкой
- email должен содержать `@` и точку в доменной части
- возраст должен быть целым числом
- возраст должен быть не менее 18 лет
