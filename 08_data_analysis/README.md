# task 11 — request security analyzer

## описание

анализ http-запросов для выявления ошибок, подозрительных ip-адресов и эндпоинтов с повышенным количеством ошибок

## что делает программа

- считает общее количество запросов
- находит неуспешные запросы с кодами 400–599
- считает запросы с кодами 401 и 403
- собирает статистику по ip-адресам
- выявляет подозрительные ip
- определяет эндпоинты с повышенным количеством ошибок
- выводит отчёт в терминал

## условия обнаружения

- ip считается подозрительным при 3 и более ответах 401 или 403
- эндпоинт считается атакуемым при 3 и более ошибках
